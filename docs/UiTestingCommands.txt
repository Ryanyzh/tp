TAssist UI branch testing

In an existing project clone (Java 25):

git fetch https://github.com/Ryanyzh/tp.git refresh-ui
git switch -c refresh-ui FETCH_HEAD
./gradlew check
./gradlew -I config/ui-demo.gradle run

If the local branch already exists, replace the git switch -c line with:
git switch refresh-ui
git merge --ff-only FETCH_HEAD

The demo launcher stores data under _temp/ui-manual-testing/session/.
Enter application commands below ONE LINE AT A TIME in its command box.
The first clear command deletes only that demo instance's saved data.
Read docs/UiTesting.md for expected results and steps between command blocks.
